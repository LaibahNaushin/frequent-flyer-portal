# Frequent Flyer Portal — ENG-163087

Responsive End-to-End Frequent Flyer Portal demo for the client capstone.

## Features
- Member dashboard and directory
- Search and empty state
- Validated member registration
- XSS-safe input sanitization
- Async loading indicators
- Offline connectivity notice
- Analytics simulation
- Accessible form errors and keyboard focus
- Vitest + React Testing Library tests

## Run
```bash
npm install
npm run test
npm run lint
npm run build
npm run dev
```

No real API keys or sensitive production PII are included.
